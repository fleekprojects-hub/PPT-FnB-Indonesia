2. Database Schema (Draft)

Tabel database internal untuk menyimpan data transaksi POS, lokasi member, & trigger cuaca: 

CREATE TABLE fbid_members (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(150) UNIQUE,
  phone_wa VARCHAR(20),
  last_pos_transaction TIMESTAMP,
  dormant_days INT DEFAULT 0
);

CREATE TABLE pos_transactions_log (
  id SERIAL PRIMARY KEY,
  member_id INT REFERENCES fbid_members(id),
  brand_name VARCHAR(50), -- Chatime / Cupbop / Gindaco
  amount_idr NUMERIC(12,2),
  created_at TIMESTAMP DEFAULT NOW()
);

4. Vercel & Production Checklist

  • Pastikan Environment Variables (`OPENWEATHER_API_KEY`, `META_WABA_TOKEN`, `RESEND_API_KEY`) sudah ter-config di dashboard Vercel.
  • Set up DNS records (SPF: `v=spf1 include:fleek.io ~all`, DKIM 2048-bit, DMARC `p=reject`) untuk domain `@fbindonesia.co.id`.
  • Konfigurasi Vercel Cron (`vercel.json`) untuk menjalankan pemicu evaluasi cuaca & dormant member setiap jam 08:00 WIB.
